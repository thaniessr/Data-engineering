========================

SSH stands for Secure Shell.

SSH is a network protocol that allows you to connect to and control another computer securely using a terminal or command line.

Important SSH commands
Command	Purpose
ssh localhost	Connect to your own computer
ssh username@192.168.1.10	Connect to another computer using its IP address
sudo systemctl status ssh	Check whether the SSH service is running
sudo systemctl start ssh	Start the SSH service
sudo systemctl restart ssh	Restart the SSH service
exit	Disconnect from the SSH session

steps to passwordless 
ssh -V
sudo systemctl status ssh
sudo apt update
sudo apt install openssh-server openssh-client
sudo systemctl enable --now ssh

Generate SSH keys
ssh-keygen -t rsa -P "" -f ~/.ssh/id_rsa

Explanation:
- ssh-keygen — Generates SSH keys.
- -t rsa — Specifies the RSA key type.
- -P "" — Sets an empty passphrase.
- -f ~/.ssh/id_rsa — Specifies where to save the keys.

This generates two files:
File	Purpose
~/.ssh/id_rsa	      Private key; keep it secret
~/.ssh/id_rsa.pub	   Public key; can be shared with the destination account

If you already have SSH keys, don't overwrite them. Check first:
ls -la ~/.ssh
cd ~/.ssh

Set SSH permissions
chmod 700 ~/.ssh
chmod 600 ~/.ssh/authorized_keys
chmod 600 ~/.ssh/id_rsa
chmod 644 ~/.ssh/id_rsa.pub
